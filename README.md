# Marvel Rivals Strategy Assistant

An AI-powered assistant that helps players optimize their gameplay in Marvel Rivals by providing character information, team composition suggestions, and strategic advice.

## Features

- Character ability explanations
- Team composition recommendations
- Synergy suggestions and counter-picks
- Game mode information
- Rank system guidance

## Setup

1. Clone the repository

## Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- AI: Anthropic Claude API
- Data Storage: JSON

## Project Structure

- `data/`: Game information (character stats, abilities, synergies)
- `public/`: Frontend files (HTML, CSS, JavaScript)
- `server/`: Backend API and Claude integration
- `utils/`: Data processing utilities
